Bank Reconciliation System
Overview

This project is a simple banking transaction reconciliation and reporting system built in Python.

The application reads transaction data from CSV files, calculates income and expenses, and generates summary information that can be used for financial reporting and reconciliation purposes.
Features

    Process banking transactions from CSV files

    Calculate total income

    Calculate total expenses

    Generate net balance summaries

    Simple and transparent reporting workflow

Technologies Used

    CSV Processing
